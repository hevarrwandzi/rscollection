## Variant: Streetwear Drop

### Design stance
A loud poster/streetwear-style drop shop, built to feel memorable instead of generic.

### Key choices
- Layout: hero poster + lookbook grid
- Typography: huge compressed-feeling bold type
- Color: cream, black, yellow, hot pink
- Interaction: bold hover cards

### Trade-offs
- Strong at: personality, drop culture, brand recognition
- Weak at: less soft/professional

### Best for
Accessory/pendant buyers who respond to hype, drops, Instagram-style branding.
