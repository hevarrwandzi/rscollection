## Variant: Real Accessory Drop

### Design stance
A new dark-premium accessory shop using the user's real images from `/home/h/Desktop/img`.

### Key choices
- Uses copied local assets under `public/assets/products/`
- Layout: featured product hero + thumbnail strip + real product grid
- Color: black, warm gold, cream
- Focus: necklaces, pendants, charms instead of generic stock accessory/pendant photos

### Trade-offs
- Strong at: realistic brand/shop feel because it uses actual inventory photos
- Weak at: source photos are screenshot/cropped style, so product photography cleanup would improve polish

### Best for
Moving from fake demo products toward the actual RS Collection shop.
