## Variant: Console Dashboard

### Design stance
A pendant-console/dashboard interface where products feel like a loadout inventory.

### Key choices
- Layout: sidebar categories + dashboard hero + inventory grid
- Typography: clean pendant UI, not cyberpunk chaos
- Color: dark navy, neon green, electric blue
- Interaction: dashboard-style menu affordances

### Trade-offs
- Strong at: gamer identity, organization, uniqueness
- Weak at: less traditional ecommerce, darker tone

### Best for
A pendant-heavy store that wants a recognizable UI concept.
