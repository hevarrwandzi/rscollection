## Variant: Manga Catalog

### Design stance
A manga/comic-panel storefront with bold outlines and story-mode buying flow.

### Key choices
- Layout: comic hero panel + manga grid + chapter steps
- Typography: heavy black type
- Color: black/white with yellow and red accents
- Interaction: strong button/card affordances

### Trade-offs
- Strong at: accessory identity, playful memorability
- Weak at: less elegant, more stylized

### Best for
An accessory-focused shop where brand personality matters more than minimalism.
