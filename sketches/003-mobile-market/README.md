## Variant: Mobile Market

### Design stance
A phone-first marketplace layout optimized for quick browsing and message ordering.

### Key choices
- Layout: search bar, category chips, product grid, order summary
- Typography: clean and readable
- Color: white, slate, green
- Interaction: add-to-order counter

### Trade-offs
- Strong at: mobile UX, ordering clarity, simple buyer flow
- Weak at: less visually unique on desktop

### Best for
Instagram/WhatsApp-driven shops where most buyers are on phones.
